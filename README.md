# TP final - EcoTech Solutions

Tres ejercicios en Python. Cada carpeta se corre por separado.

| Carpeta | Qué contiene | Cómo correrlo |
|---|---|---|
| `solucion_ejercicio_1` | Sanitización y análisis estadístico de sensores | `python main.py` |
| `solucion_ejercicio_2` | Modelo de productos, excepciones y persistencia en JSON | `python main.py` |
| `solucion_ejercicio_3` | Tests con unittest y vista de Django | `python -m unittest -v` |

Notas:

- En el ejercicio 2, `main.py` genera el archivo `catalogo_ecotech.json`.
- En el ejercicio 3, los tests no necesitan Django. `views.py` está pensado para vivir dentro de una app de Django (`pip install -r requirements.txt`).
